# Web model sources

Checked on 2026-11-23 using the upstream model index and GitHub file-tree metadata. Every binary path below exists at its pinned revision; sizes are original repository file bytes, not measured HTTP transfer sizes. These are real GLB download URLs, not model-gallery pages.

The 100 Three.js prompts reuse 27 assets in different compositions. The motion is intentionally simple, but some source files are large. For a small Carrd hero, download and optimize a local copy, then serve that copy from the same origin or a correctly configured asset CDN. A starting target is about 2 MiB per shipped model with roughly 1K textures, adjusted after inspecting quality and measured performance. The originals are not already optimized to that budget.

No model binaries are added by this prompt collection. Check the linked per-model credits before including model files or derived posters in a deployed project. Khronos is the collection host; it is not necessarily the creator or a blanket license for every asset. Preserve separate model, texture, rigging, animation and conversion credits where listed.

## Implementation notes

- Use GLTFLoader with the binary URL or a local downloaded copy. A cross-origin request still needs the source server's CORS policy to allow it. If that fails, serve a permitted local copy; changing fetch to no-cors will not make an opaque response loadable.
- The table confirms repository paths and sizes. It does not claim that all files were downloaded into a browser, rendered, CORS-tested or visually inspected in this task. Test the selected asset when implementing its prompt.
- Read each GLB's required extensions and supply the matching loader support. These links use the ordinary glTF-Binary variant; some materials still rely on glTF extensions.
- MaterialsVariantsShoe is used in its default material state. Variant switching would need explicit support and is outside these simple loops.
- Fox exposes Survey, Walk and Run clips. Its source README lists separate credits for model, rigging/animation and glTF conversion. Use one active clip unless an intentional blend is implemented.
- AnimatedMorphCube supplies morph-target animation; inspect its clips rather than creating unsupported target names. CesiumMan and RiggedFigure prompts also instruct the implementer to inspect available clips.
- Independent skinned clones need independent skeletons. Reuse immutable geometry/textures, and dispose shared resources only after their final consumer is removed.
- CSS posters and cutouts are prepared assets, not files supplied by this collection. Generate them during implementation from the corresponding licensed model, or make the requested original CSS illustration. CSS itself cannot fetch and display a GLB.
